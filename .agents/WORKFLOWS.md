# Global Workflow Commands

When a user request begins with a command, read the corresponding local skill file in addition to `AGENTS.md`:

- `#ask`: `.agents/skills/ask.md`
- `#grillme`: `.agents/skills/grillme.md`
- `#plan` (or `/plan`): `.agents/skills/plan/SKILL.md`
- `#exec`: `.agents/skills/exec.md`
- `#flash`: `.agents/skills/flash.md`
- `#review`: `.agents/skills/review.md`
- `#refactor`: `.agents/skills/refactor.md`
- `#delegate` (or `#deligate`): `.agents/skills/delegate.md`
- `#solve` (or `/solve`): `.agents/skills/solve/SKILL.md`
- `#deep-refactor` (or `/deep-refactor`, `#refrag`): `.agents/skills/deep-refactor/SKILL.md`
- `#bundle` (or `/bundle`, `#repomix-split`): `.agents/skills/bundle/SKILL.md`
