Installationsanleitung:

1. Node.js installieren (https://nodejs.org/).
2. Repository klonen oder Code herunterladen.
3. Im Terminal im Hauptverzeichnis 'npm install' ausführen.
4. Eine '.env' Datei im Hauptverzeichnis anlegen (basierend auf '.env.example') und deine Cloudflare R2 Credentials eintragen.
5. Mit 'npm run dev' starten.
